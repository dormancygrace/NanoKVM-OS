# mDNS, SSH and owned password updates

Admin mDNS enable/disable and SSH status/enable/disable preserve the baseline API and persistent policy. Alpine keeps mdns_disabled separate from package-owned OpenRC scripts. Legacy mDNS copies the rooted Avahi script before starting and removes its PID/script after stopping. A fixed avahi-daemon -k command replaces shell interpolation of PID-file contents. The password field remains password in JSON and Password in Gin forms; the differential oracle caught and corrected this distinction.

SSH enable first validates/decrypts and updates the root password, then invokes S50sshd permanent_on. Disable invokes permanent_off. Root password updates use a new owned process group, stdin only, the BusyBox100ms confirmation interval,10-second deadline, request/shutdown cancellation and reaping. Credentials never enter arguments/environment/output. CR/LF/NUL passwords are rejected because the stdin line protocol cannot represent them faithfully. This is an intentional correction to the old implementation.

Owner-account password synchronization uses this same injectable backend and shares the system-settings lock with SSH password changes. Backend failure restores the exact previous account database. A dropped request cancels the password process and cannot proceed to enable SSH. Native isolated roots refuse all service/password commands before making effects.

Qualification:41 actual immutable Go Gin cases for JSON/form binding, responses, password-before-service order, policy markers and legacy copy/cleanup, with fixture commands/password only. Three integration tests and one real local stdin/timeout/cancel unit added.158 tests pass on host and generic riscv64 musl/QEMU, together with fmt/clippy, static release and certificate-verified TLS. See stage3-services-qualification.json. No host/device passwd, Avahi, SSH service or firmware helper was executed; no stand configuration changed. Hardware service and password behavior still requires the agreed device window.
