# URL form binding correction

The generic Rust request parser now follows the exact Gin v1.12 Form path and matched Go net/http Request.ParseForm rules: merge body values before URL query, preserve first scalar and repeated slice order, read urlencoded bodies only for POST/PUT/PATCH, treat absent Content-Type as octet-stream, and ignore body on GET/DELETE or unrelated media types. JSON still binds its body independently of URL query. Malformed percent escapes and raw semicolon separators fail before any handler writes a setting, including when an invalid field is otherwise unknown.

Media type and parameter syntax uses maintained mediatype 0.23.0 with a small Go adapter. The shared Go MIME/disposition parser permits a no-slash opaque token, equal duplicate parameter values and a trailing empty separator; unequal duplicates remain invalid. The adapter keeps those behaviors while using mediatype's parameter parsing. Official repository https://github.com/picoHz/mediatype is nonarchived, last pushed 2026-07-27; crates.io stable release 0.23.0 was published 2026-07-27 under MIT. The existing transitive hyperium/mime remains untouched; its last push was 2024-10-31 and it was not selected as the new direct parser. This introduces one resolved package, with no extra parser transitive dependencies.

scripts/refresh-v3-form-oracle.py runs the same matched Go net/http primitive used by Gin and emits 27 actual cases: body/query order, method/media/default rules, MIME parameters, first scalar/repeated slices, escape errors, semicolons, Unicode and response replacement of invalid UTF-8. API regression checks verify title-file side effects and unchanged contents after parse failure, JSON query exclusion and DELETE query ID versus ignored body. The paste table generator now formats its generated Rust constants automatically for reproducible fmt checks.

Qualification: check-v3.py --host --target --tls passes 82 tests on both architectures (33 unit, 21 API, nineteen socket/paste tests, nine USB/monitor tests), fmt, warning-denied clippy, static generic riscv64 musl/QEMU and verified TLS lifecycle. The maximum 833-key paste remains included. All 164 resolved SPDX declarations are present. No native firmware commands or stand changes.

This is JSON/urlencoded/query qualification, not complete support for every Gin encoding. Multipart/file uploads, XML/YAML/TOML/MsgPack/ProtoBuf and exact raw invalid-byte persistent-field semantics remain integration work. Native GPIO/system/media/addons/package/hardware parity remains pending; ledger is still 32 isolated routes, one partial WS, 171 pending. Production activation stays refused and H.265 WebRTC remains unconditionally disabled.
