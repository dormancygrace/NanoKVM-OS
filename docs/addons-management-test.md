# Проверка меню расширений и временных паролей RustDesk

Устройство: тестовый стенд. Дата: 2026-10-03.
Код сборки: bbc7aea, ветка codex/rustdesk-addon-20261003.
Установлены nanokvm-app 2.0_beta8-r3 и nanokvm-rustdesk 0.2.0-r0.

## Интерфейс

- Software → Add-ons: карточка пакета, версия, установить / обновить / удалить,
  переход «Открыть управление». Полей настройки RustDesk здесь больше нет.
- Settings → Extensions → RustDesk: один экран управления, статус, ID,
  временный пароль, копирование, новый пароль, включение службы и режим пароля.
- Собственный сервер, видеокодек и число зрителей находятся в Advanced settings.
- В меню отображаются установленные расширения. Остановленная служба остаётся
  доступной. После удаления RustDesk пункт исчез; после переустановки вернулся.
- Пункт PicoClaw открывает его существующую панель. Сам PicoClaw на этом устройстве
  не устанавливался; его рабочая панель в данном цикле не проверялась.
- Интерфейс осмотрен в Chrome Main на desktop. Подписи EN/RU проверены сборкой;
  отдельная проверка мобильной компоновки в этом цикле не проводилась.

## Пароль и жизненный цикл

- Для новой конфигурации выбран автоматический временный пароль.
- Старые конфигурации при обновлении сохраняют постоянный режим.
- Проверено сохранение постоянного секрета при обновлении и смене режима:
  сравнивались SHA-256, сам секрет в отчёт не включён.
- Временный пароль содержит 10 читаемых символов и создаётся из случайности ОС.
- Новый пароль меняется при запуске службы или по кнопке; кнопка предупреждает,
  что текущие подключения завершатся.
- На устройстве проверены генерация, смена по кнопке, удаление временного файла
  при остановке и создание другого пароля после повторного запуска.
- Временный файл имеет права 0600 root:root, каталог /run закрыт для других
  пользователей. ID 1320947846 сохранился после обновления, удаления и переустановки.
- Временный пароль доступен в администраторском API. Постоянный пароль из API
  статуса не возвращается. Эти маршруты защищены CheckToken и RequireRole(admin).
- В конце проверки RustDesk включён, добавлен в default runlevel, зарегистрирован
  на штатном ID-сервере и работает в режиме временного пароля.

## Проверки

- Rust: 23 passed, 2 live tests ignored. Экспортируемые vendored-исходники проходят
  те же тесты с --locked --offline.
- Go: полный go test -tags teststub ./... прошёл. Дополнительные проверки покрывают
  миграцию, отсутствие постоянного секрета в ответах, выдачу временного пароля
  только при работе службы и безопасную смену пароля без изменения конфигурации.
- Web: TypeScript, Vite production build и ESLint изменённых файлов прошли.
- Настоящий установленный Windows RustDesk 1.4.9 принял временный пароль через
  зашифрованный relay и получил кадры 1440x2560 H.265. Сеанс прерывался при
  USB-вводе с HTTP 409, поскольку браузер удерживал управление; стабильность
  совместного ввода в этом цикле не квалифицирована.
- Сохранены Direct H.265, 1440x2560 portrait, общий режим энкодера и USB-композиция
  с единственным hid.GS2. Устройство не перезагружалось.
