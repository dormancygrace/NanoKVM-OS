# Third-party software

This is a derivative firmware project, not an original implementation of every component.

- NanoKVM application/native code: Sipeed and contributors, GPL-3.0; see root `LICENSE` and retained source headers.
- Linux and applicable drivers: their upstream licenses, including GPL-2.0; kernel patches retain source notices.
- The server links, pinned in `platform/sources.lock`: [libwebsockets](https://github.com/warmcat/libwebsockets) (MIT), [glaze](https://github.com/stephenberry/glaze) (MIT), [rapidyaml](https://github.com/biojppm/rapidyaml) (MIT), [libdatachannel](https://github.com/paullouisageneau/libdatachannel) and [libjuice](https://github.com/paullouisageneau/libjuice) (MPL-2.0), [libsrtp](https://github.com/cisco/libsrtp) (BSD-3-Clause), [usrsctp](https://github.com/paullouisageneau/usrsctp) (BSD-3-Clause), [plog](https://github.com/SergiusTheBest/plog) (MIT), [libjpeg-turbo](https://github.com/libjpeg-turbo/libjpeg-turbo) (IJG, BSD-3-Clause, zlib), [libspng](https://github.com/randy408/libspng) (BSD-2-Clause), [live555](http://www.live555.com/liveMedia/) (LGPL-3.0-or-later) and [curl](https://curl.se/) (curl license).
- Web dependencies retain their package licenses; versions are pinned in `web/pnpm-lock.yaml`. [Mediabunny](https://github.com/Vanilagy/mediabunny) (MPL-2.0), which writes Direct and WebRTC recordings into MP4, is bundled unmodified; its source is the published npm package of the pinned version. The interface font is [Inter](https://github.com/rsms/inter) (OFL-1.1), from the `@fontsource-variable/inter` package of the pinned version, bundled unmodified.
- The C906 assembly generators in `firmware/cpu/go-crypto-c906` retain the Go license (`LICENSE`) and the CRYPTOGAMS license (`CRYPTOGAMS-LICENSE`).
- SOPHGO/CVITEK MPI, ISP, drivers and sensor dependencies have component-specific terms. No closed ISP/3A algorithm object is built or shipped: the HDMI receiver's YUV bypasses the ISP's image processing; this repository does not claim a completely open-source replacement for those objects.
- The computer sensors Windows agent (`addons/host-sensors`, [documentation](HOST-SENSORS.md)) is one exe that contains, unmodified: [LibreHardwareMonitorLib](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) (MPL-2.0) with the [PawnIO modules](https://github.com/namazso/PawnIO.Modules) it embeds (LGPL-2.1), its NuGet dependencies ([DiskInfoToolkit](https://www.nuget.org/packages/DiskInfoToolkit), [RAMSPDToolkit-NDD](https://www.nuget.org/packages/RAMSPDToolkit-NDD), [HidSharp](https://www.nuget.org/packages/HidSharp) and Microsoft's `System.*` packages, under their package licenses), and the installer of the [PawnIO](https://github.com/namazso/PawnIO) driver (GPL-2.0, with its exception for programs that only talk to the driver), taken from the latest release of [PawnIO.Setup](https://github.com/namazso/PawnIO.Setup) when the add-on is built.
- [libopus](https://opus-codec.org/) 1.6.1 (BSD-3-Clause, [COPYING](licenses/opus-COPYING)) is compiled into the program of the small core that `nanokvm_c906l` embeds; the archive is pinned in `platform/sources.lock`.
- The optional ZeroTier add-on (`nanokvm-zerotier`) is ZeroTier One's agent under MPL-2.0, built without its source-available network controller; its bundled `ext/` code keeps its BSD-3-Clause, MIT and Apache-2.0 licenses, installed under `/usr/share/licenses/nanokvm-zerotier`.
- OpenVPN, Tailscale, Buildroot packages, Wi-Fi firmware and toolchain components retain their individual licenses. Building or distributing a full image requires corresponding source and firmware notices beyond the application license.

The [platform build](../platform/README.md) describes the corresponding source of the kernel, modules, U-Boot and initramfs, the other copyleft components of the image, and the written offer. The repository is not a complete corresponding-source distribution for every full-image component. The license texts and manifest of the initramfs userland and C library come from Buildroot's `legal-info` at build time and are installed in `/usr/share/licenses/nanokvm-kernel/initramfs`. Alpine packages declare their licenses in the `L:` field of `/lib/apk/db/installed`; each build lists them in `release/installed-licenses.txt`. Missing vendor firmware terms and external build inputs are listed in [distribution status](DISTRIBUTION.md). Preserve upstream copyrights and attribution; the application license does not grant rights over every included firmware blob.
