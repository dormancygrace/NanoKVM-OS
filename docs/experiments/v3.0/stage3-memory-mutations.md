# Swap and video memory mutations

Admin POST memory/swap and memory/video and legacy GET/POST swap now preserve the Go API's JSON/form binding, validation, error messages and returned state. ZRAM accepts32/64/128/162MiB; SD128/256/512MiB. The optional recompression flag is ZRAM-only. Legacy size0 disables SD with its256MiB setting.

Actual work remains in S38memory and activate-kernel. Rust passes only typed constant arguments, shares the memory mutation mutex and the existing /kvmapp/.os-update/lock with updates, and owns the nonblocking regular-file flock. Final symlinks and nonregular locks are refused; an owned directory descriptor prevents final lock-parent substitution. Video selection checks both board images and uses a90-second command deadline. Swap commands have a120-second deadline. Request drop/shutdown cancels active command process groups and waiting mutations.

Combined stdout/stderr preserves pipe ordering while retaining bounded raw/trimmed tails and a bounded warning prefix. This preserves Go's differing trim-before-tail swap and tail-before-trim video messages, including invalid UTF8 and arbitrarily long trailing whitespace. The single15-second maintenance worker runs nice19 only for an exact enabled setting and active zram, does not overlap commands, resets warning deduplication after success and cancels on shutdown. S38memory's own flock retains skip-on-contention behavior.

Qualification:66 cases replayed from immutable Go with fixture command/lock/state substitutions, four unit and six integration tests added,154 total tests pass on host and generic riscv64 musl/QEMU. Real local command fixtures cover combined ordering, failure, tail bounds, cancellation, floods and inherited pipes. Owned fixture flock/permissions/link/FIFO guards, actual API roles/effects, shared-mutex cancellation, dropped HTTP permit recovery and actual15-second worker shutdown pass. fmt, clippy, static release and real TLS gates pass; hashes in stage3-memory-mutations-qualification.json.

No memory helper, swap, kernel selector, host password/service or device mutation was executed. Native isolated roots refuse firmware commands; injected fixtures provide effects. Kernel/helper hardware behavior, native memory budget/Go soft memory limit, full image packaging and production activation remain pending. No Go runtime bridge was introduced.
