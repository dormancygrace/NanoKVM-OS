NanoKVM shutdown

Waiting for shutdown checks. Keep power connected.

Video, keyboard, virtual disks, SSH and add-ons stop during shutdown. The connected computer is not shut down.

Keep this browser tab to start NanoKVM again, or save its restart key in a private place. The key is valid only until the next boot.

Restart key

Network restart works while NanoKVM still has power. After power is disconnected and restored, NanoKVM OS starts normally.
