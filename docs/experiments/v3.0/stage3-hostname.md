# Hostname configuration slice

GET hostname is session-readable; POST is admin-only. JSON uses Go case folding, duplicate order and nonpointer null semantics; urlencoded forms use exact Hostname, first scalar and body-before-query precedence. A hostname is 1..253 bytes, composed of 1..63-character ASCII DNS labels with letters/digits at both ends and hyphens only inside. The immutable baseline generator extracts and executes the actual validator and whole-host-token replacement functions: 16 validation, 5 text and 2 raw-byte cases.

The hosts edit replaces matching name tokens after the address, preserves other names/lines and comments, and normalizes changed body fields to tabs exactly like Go. Unicode whitespace is recognized with byte ranges; unrelated invalid UTF-8 survives unchanged, including an old invalid-byte hostname. GET JSON retains Go's replacement behavior without rewriting file data.

Writes retain baseline order: hosts when the name changes, boot/hostname, then etc/hostname, with exact error codes/messages and atomic 0644 files/fsync. Missing hosts is allowed on an unchanged name. A settings mutex serializes simultaneous persistent changes. Firmware paths resolve inside the runtime root, retaining Alpine absolute symlinks. This intentionally preserves a compatibility symlink while replacing its target rather than destroying the link. The native hostname-F action is fixed, bounded 5 seconds and refused in isolated roots; its failure does not change persistent-success semantics, as in Go. No host/device hostname command ran.

check-v3.py --host --target --tls passes 99 tests per architecture: 37 unit, 23 API, 19 socket/paste, 9 USB/monitor and 11 GPIO/system. It includes prior ATX/USB/HID and 833-key paste, static generic-rv64 musl/QEMU, warning-denied host clippy, real verified TLS/redirect/Secure cookie/SIGTERM/occupied-port. 164 resolved SPDX packages; no dependencies added. Qualification JSON records exact release and log hashes. Ledger: 38 isolated / 1 partial WS / 165 pending of 204 routes.
