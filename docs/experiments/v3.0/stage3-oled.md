# OLED preference and Go JSON correction

Both OLED routes remain admin-only. GET reports missing display or sleep preference with the baseline defaults, parses signed stored integers and preserves the malformed-config error. POST accepts the exact ten supported sleep values, including -1 and 0; missing/null optional Sleep defaults to 0. JSON case folding, duplicates/nonpointer nulls and first-form Sleep/body-before-query are preserved. The setting has exact decimal bytes without a newline; atomic replacement keeps an existing file mode and uses 0644 for a new preference. Nonregular files and confined-path failures return the baseline write error. No native display command runs.

Signed Go int64 binding uses raw JSON numeric tokens, including -0, which serde's default integer visitor otherwise rejects. Nineteen actual baseline proto/Gin cases verify signed bounds, under/overflow, floats/exponents, wrong types, duplicate errors, unknown huge numbers and trailing JSON. The same prepared target field supports the pending CPU handler; no CPU route is claimed yet.

Thirteen actual baseline Go string/key cases verify individual replacement of invalid UTF-8 bytes, lone high/low UTF-16 escape replacement, valid pairs, escaped backslashes and unknown fields. A small compatibility normalizer wraps the maintained serde parser; every struct/shortcut binder uses the iterative Go 10000-depth syntax check. Hostname GET now uses the same per-byte JSON text replacement. Raw hosts-file preservation remains intact. URL-form raw-byte persistence and complete non-JSON/form encodings remain separate integration work.
