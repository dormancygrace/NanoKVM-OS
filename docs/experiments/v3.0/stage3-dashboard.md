# Read-only system dashboard

Session GETdashboard embeds system, optional memory, hardware, application and image identity. Rooted proc/sys reads preserve hostname/kernel trimming, CPU counters (first eight fields, exclude guest, wrapping unsigned sums), uptime/load/nulls, hardware cpuinfo frequency and board hwmon preference with thermal fallback. Invalid sensor readings remain null, including legitimate0C. Nonfinite uptime is deliberately null to preserve valid JSON.

CPU usage samples independently every second and becomes unavailable after three seconds. Initial/reset/reversed/impossible counters remain null and valid intervals recover. The worker retains only Weak ownership between ticks, runs file reads outside the Tokio executor and aborts on shutdown. Five integration tests include an actual timer with no HTTP calls, shutdown/staleness and ownership cleanup.

Only mounted root/boot/data paths report filesystem capacity. Blocks follow GoStatfs arithmetic; the public fstatvfs read-only flag comes from the same owned O_PATH descriptor because GNUlibc0.2.190 hides statfs.f_flags. [Linux libc documentation](https://man7.org/linux/man-pages/man3/statvfs.3.html) documents that flag and the underlying Linux statistics interface. The riscv64musl unsigned f_bsize is converted by bytes to preserve signed Go field bits. Affinity counts exclude CPUs outside the process mask.

Owned getifaddrs data provides addresses and masks; a bounded read-only RTM_GETLINK dump provides kernel kind, MAC and MTU. Kernel sender/sequence/framing/interrupted dump errors reject incomplete metadata. Receive time is bounded1sec, datagrams64KiB and count1024. Interface preferences remain independent of carrier: eth0/VLAN marker, wlan0 marker, carrier0 override, wireless directory/name and unsigned counters. Loopback is omitted. IPv4-mapped and non-CIDR IPNet strings match Go. Basic info discovery remains independent of this optional metadata dump. Isolated roots refuse host network/affinity/filesystem telemetry and accept trusted fixture backends.

Fifty-three immutable actual Go filesystem/interface/statfs scenarios, seven interval/stale cases, five IPNet strings and six attribute cases match. Two netlink unit tests cover nested kind/flags/padding/MTU/MAC/dump/errors. Native affinity, same-descriptor filesystem flags and repeated owned network calls pass on host and static generic-rv64musl/QEMU. The Go live-disk snapshot is retained as point-in-time evidence rather than a host-capacity fixture requirement.
