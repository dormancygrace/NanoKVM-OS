# HTTP HID paste

POST /api/hid/paste preserves the US/de/fr/es character maps, explicit lower-case form tags content/langue, unsupported-rune skipping, Spanish dead-key continuation, 30ms cadence, 833-rune/3332-byte/25-second key-count budget and exact -1/-2/-3 responses. Native Rust layout constants are generated by scripts/refresh-v3-paste-oracle.py from verbatim immutable-baseline Go functions in ignored work/. The final runtime contains no Go dependency or transport bridge.

One paste runs per keyboard. Manual admission preempts addons and respects PicoClaw ownership; the manual lease remains active through the whole paste. Every stroke revalidates current principal, token version/expiry, mode, ownership lease and the captured Hub generation. Press/release pairs run under the input transition lock, which is released during sleep. Ownership transfer or USB reconfiguration cancels an existing paste even when a browser lease is retained. Final cleanup cannot clear a new owner's keys. Physical errors retain neutral-retry behavior, and final-release errors are preserved alongside the original cause. Successful strokes update jiggler activity.

Dropping an HTTP handler cancels its blocking work and wakes the cadence timer. Real TCP disconnect, future abort, token revocation, Pico ownership and mode transition are tested. The original 25 seconds is a theoretical key-count limit; enforcing it as a wall-clock cutoff would incorrectly reject the maximum valid paste once IO/scheduler overhead is added. A separate 28-second drain ceiling preserves this boundary and remains below the existing 30-second mode-switch wait, with time for final neutral cleanup.

Qualification: check-v3.py --host --target --tls passes 80 tests on both architectures (32 unit, 20 API, nineteen existing/paste socket tests, nine USB/monitor tests), fmt, warning-denied clippy, static generic riscv64 musl/QEMU and verified TLS lifecycle. All 437 actual-Go layout entries produce exact HID sequences; every Spanish continuation and final key-up is checked. The actual 833-character sequence completes with the required cadence on host and target. Additional cases cover length/dead-key duration errors, unsupported emoji, owner transfer without clearing the new owner's held key, concurrent-paste refusal, request abort/TCP disconnect/revocation, USB generation, mode drain and Pico lock.

The source review also found a separate generic form-parser gap: URL query merging, body/content-type/method rules and malformed-percent handling need immediate correction against actual Go fixtures. This qualification covers JSON and explicit urlencoded-body paste, not all Gin input encodings. Native audio/monitor, other system/config routes, media/addons/package/image/hardware remain required. Ledger: 32 isolated implementations, one partial WS, 171 pending. Stand unchanged; production activation remains refused.
