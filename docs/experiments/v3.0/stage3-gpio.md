# GPIO/ATX and hardware slice

Rust implements session hardware/ATX LED reads, session plus input-owner ATX writes, and admin reboot. Cached image/board detection preserves legacy Alpha/Beta/PCIE sysfs mappings, the Enhanced marker, board-profile precedence, Lite compatibility and disabled pins on unknown Enhanced boards. Linux GPIO-v2 uses controller labels and local offsets with exact matched UAPI, initial inactive output values, offset bounds and owned line descriptors. Legacy sysfs uses an existing pinned descriptor without recreating a removed node. Isolated roots refuse native GPIO-v2 requests.

ATX pulses default to 800ms and permit 1..60000ms. One try-lock rejects overlap. Request disconnect, session/token revocation, runtime stop or ownership-generation changes cancel within the 20ms check cadence. Every acquired output deasserts and closes on success, activation failure, cancellation or panic; cleanup errors retain the original cause. GPIO pulses do not incorrectly hold a HID mode lease beyond that mode's drain limit.

The lazy LED worker samples 20ms, inverts active-low signals and holds HDD activity 350ms. HDD input is optional. Open/read failures close both inputs, retain cleanup errors and reopen after 1s. Stop wakes and joins the worker, including before the first read; the worker owns no Runtime reference cycle.

ATX JSON/urlencoded/query binding preserves uint64 boundaries, Go case folding, duplicates, nonpointer nulls, form field names and first scalar. scripts/refresh-v3-gpio-oracle.py verifies proto files against immutable baseline before running the actual proto.ParseFormRequest, Gin and validator. 47 cases include malformed syntax, overflow, invalid types, unknown huge numbers, trailing JSON and 10000-level depth. An iterative compatibility diagnostic adapter avoids a recursion cap/stack overflow; serde_json remains the maintained value parser. UAPI sizes/offsets/ioctls equal Go x/sys, host C execution and matched riscv64 C static assertions. A tuned platform libc cannot execute as generic QEMU C code; Rust itself qualifies as generic-rv64.

Review also repaired shared JSON binding: unknown fields are skipped rather than materialized as numeric Values, and Gin accepts a single decoded value even when another follows. Form-bound shortcut JSON still requires a complete value. The cancellation notification now holds its condition mutex, preventing a lost wake. The deprecated musl time_t alias is inferred through gmtime_r's actual FFI type.

Reboot response precedes one deduplicated delayed action. Executor preflight refuses unavailable/stopped native backends before acknowledging it; execution repeats the root/stop guard. Errors use the baseline operation-failed response. A delayed execution failure is logged. Fixture executors only record commands; no firmware reboot occurred.

Qualification: check-v3.py --host --target --tls passes 96 tests per architecture (36 unit,21 API contracts,19 socket/paste,9 USB/monitor,11 GPIO/system), fmt, warning-denied host clippy, static generic riscv64 musl/QEMU and verified TLS/307/Secure cookie/SIGTERM/occupied-port. Includes real TCP disconnect during an asserted 60s pulse, overlap/error/panic cleanup, active-low/HDD hold/retry/optional cleanup, board detection and admin delayed reboot plus native isolated refusal. Atomic replacement now explicitly sets requested permissions, matching Go even under a restrictive umask; a separate own child-process proves 755/644/600 modes without racing parallel tests. No new resolved packages; 164 SPDX packages.

This remains isolated feature qualification. Real GPIO pin behavior/timing, kernel descriptor lifecycle, native media, full system/addon/package and hardware parity are pending. Other Gin encodings, exact invalid-byte persistence and exhaustive syntax/string diagnostic compatibility remain generic binder integration. Production activation remains refused. Ledger: 36 isolated / 1 partial WS / 167 pending of 204. No stand mutation or release publication; H.265 WebRTC remains disabled unconditionally.
